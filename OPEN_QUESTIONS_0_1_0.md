# Open Questions 0.1.0

**Status:** pre-inception question set  
**Rule:** questions are not conclusions

1. What should count as the project's first bounded research question?
2. Which theological claim types require distinct methodologies?
3. What source hierarchy, if any, should govern Christian theological questions?
4. How should canonical scripture, extracanonical texts, patristic sources, councils, confessions, and later theologians be weighted?
5. How should historical-critical scholarship interact with confessional interpretation?
6. What does an equal-standard comparison mean when traditions disagree about authority itself?
7. How should the project distinguish historical evidence for a belief from evidence that the belief is true?
8. How should miracle claims be evaluated without either assuming naturalism or suspending ordinary historical standards?
9. How should philosophical arguments interact with revealed-theology claims?
10. How should uncertainty be represented?
11. Can doctrinal systems be compared without flattening important internal differences?
12. What constitutes a failed theological argument?
13. How should negative findings be preserved?
14. Should the project preregister comparison criteria before examining rival traditions?
15. What would count as convergence, and should convergence even be expected?
16. How should personal faith commitments be disclosed without allowing them to control outcomes?
17. How should non-Christian traditions enter the program if a question genuinely requires broader comparison?
18. Which theological structures, if any, are suitable for Invariant Structure Research?
19. What safeguards are needed to prevent superficial analogy between theology and physics?
20. What first study would most effectively test whether this project can be rigorous without becoming either apologetics or reductive skepticism?
