## 1. Purpose

EMT began as a user-supplied intuition about a possible long development chain:

```text
environmental observation
→ storm / rain / fertility religion
→ lightning-associated places / stones
→ deliberate placement / stone construction
→ monumental architecture
→ geometry / technical specialization
→ Mediterranean knowledge transmission
→ Hellenistic / Jewish / Egyptian interaction
→ later theology
```

The hypothesis was preregistered before substantive evidence review.

Stage 1 has now tested:

- the original chain;
- Geoffrey Drumm's proposed functional mechanism;
- Saharan–Nile continuity;
- hydrological substitution;
- middle-period carrier continuity;
- motif continuity;
- Graham Hancock / Randall Carlson as alternative-hypothesis sources;
- and the transition from archaeology/iconography into explicit Old Kingdom textual theology.

This checkpoint prevents further work from silently expanding EMT into the whole TFP.

## 3. Strongest positive historical result

The strongest result is **not** the lightning-specific chain.

It is a broader Northeast African transformation model:

```text
Holocene environmental experience
→ Saharan pastoral / ritual landscapes
→ desert–Nile interaction
→ material + mortuary + pastoral carrier continuity
→ Badarian / Naqada transformation
→ inundation-linked ritual
→ Early Dynastic celestial/hydrological formalization

```

This broad model has support from multiple independent evidence classes.

## 6. Archaeology → writing result

The earliest substantial written religious corpus does not simply reproduce prehistoric symbolism.

It **refunctionalizes** culturally dense forms.

The strongest pattern is:

```text
LIVED ECOLOGY
→ SOCIAL PRACTICE
→ RITUALIZATION
→ ELITE / ROYAL APPROPRIATION
→ TEXTUAL THEOLOGY
```

Examples:

- boat → transport → ritual procession → cosmic ferry;
- cattle → pastoral wealth/power → ritual symbol → divine maternity / kingship / sky;
- water → survival / fertility → seasonal ritual → state cycle → rebirth / inundation / cosmic regeneration.

## 7. Lightning-specific result

The original lightning intuition remains partially interesting but does not currently supply the main bridge.

Stage 1 found:

- physical plausibility of recurrent strikes at exposed locations;
- ancient sacralization of some lightning-struck places;
- later "thunderstone" traditions involving curated stone objects;
- Geoffrey Drumm's explicit lightning/chemical monument model.

Stage 1 did **not** establish:

- an early Holocene Egyptian thunderstone tradition;
- deliberate relocation of lightning-struck stones to induce storms;
- stone circles as lightning technology;
- pyramids as evolved lightning collectors;
- Drumm's functional chemical model.

The Drumm lane is presently blocked chiefly by **raw analytical data + provenance + independent replication**.

## 11. EMT reactivation conditions

EMT should be reopened only for a bounded reason such as:

1. new raw Drumm / ISIDA laboratory data with traceable provenance;
2. a credible archaeological find directly linking lightning-associated material to early Northeast African ritual;
3. stronger evidence for named symbolic transmission across Western Desert → Badarian → Naqada;
4. a focused later-theology study that genuinely requires one EMT result;
5. an independent audit challenging a Stage-1 disposition.

Interest alone is not sufficient to restart unrestricted EMT expansion.

## 12. Program routing

TFP now returns to its founding problem:

> How can a theology-native research program compare competing claims without becoming disguised apologetics and without importing inappropriate standards from unrelated disciplines?

The next phase should refine and stress-test `TFP_METHOD_SEED_0_1_0.md` against a **non-archaeological theological problem**.

This is necessary because EMT was archaeology/history-heavy.

A mature TFP method must also work for:

- textual criticism;
- historical-event claims;
- philosophical argument;
- doctrinal development;
- authority disputes;
