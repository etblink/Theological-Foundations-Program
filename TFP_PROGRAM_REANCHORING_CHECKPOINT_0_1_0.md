# TFP Program Re-Anchoring Checkpoint 0.1.0

**Status:** proposed program-steering checkpoint — requires human-owner confirmation  
**Date:** 2026-10-05  
**Reason:** prevent methodology/qualification drift from becoming the program

## 1. Governing big picture

The Theological Foundations Program is a truth-seeking research program.

Its governing purpose is:

> Determine which theological claims, interpretive frameworks, and doctrinal structures, if any, are true—or closest to the truth available to us—while making evidence, assumptions, standards, disagreements, uncertainty, and unresolved underdetermination explicit.

The immediate methodological task exists to serve that purpose.

**The adjudication protocol is infrastructure for TFP. It is not TFP itself.**

## 2. Drift warning

The program has now spent multiple successive cycles on:
- protocol repair;
- qualification mechanics;
- auditor independence;
- source manifests;
- role-control records;
- STATE transitions;
- re-audits of the protocol itself.

This work has produced real improvements, but it now presents a recognizable drift risk:

> success can silently become “produce a protocol that no auditor can criticize” rather than “use a sufficiently reliable protocol to discover what is true.”

The current Protocol is already large and highly procedural. Further complexity carries costs:
- cold-start burden;
- more joints that themselves require auditing;
- greater chance that meta-governance generates its own defects;
- delay before substantive theological evidence is actually evaluated.

## 3. What the 0.1.6 audit means

The 0.1.6 audit must not be waved away.

Its five MAJOR findings are concentrated at real outcome/qualification joints:
- outcome partition;
- evidence/disposition → directional comparison;
- post-evidence amendment consequences;
- qualification STATE transition;
- role-control completeness.

These are worth repairing before canonical truth adjudication.

But the audit does **not** imply that every conceivable methodological edge case must be solved before TFP studies theology.

## 4. Proposed anti-drift rule

If the human owner confirms this checkpoint:

### A. One bounded qualification repair
Authorize one bounded successor repair focused on:
- the five accepted MAJOR defects;
- only MINOR defects that directly interact with those MAJOR surfaces, qualification validity, or cold-start executability.

Do not add new generalized machinery merely because it might someday be useful.

### B. Qualification exit criterion
The next audit should be treated as a **qualification gate**, not an invitation to endlessly redesign.

If the next immutable candidate receives:
- `PASS`; or
- `PASS_WITH_LIMITATIONS`;

with no unresolved BLOCKING/MAJOR defect and no MINOR cluster that the protocol itself says forces `REPAIR_REQUIRED`, the program should qualify the protocol rather than chase non-outcome-determinative perfection.

### C. Novel-defect brake
If the next fresh audit returns `REPAIR_REQUIRED` primarily because of **newly created meta-methodological machinery**, do not automatically create another protocol version.

Instead perform a simplification review:
- remove unnecessary machinery;
- move nonessential qualification mechanics out of the core study protocol;
- prefer fewer explicit rules over recursive governance complexity.

### D. After qualification
Once a protocol qualifies:

1. freeze it;
2. shift methodology into maintenance mode;
3. authorize a bounded substantive stress test under a separately frozen study preregistration;
4. let subsequent protocol revisions be driven mainly by failures observed in real studies rather than speculative protocol-only adversarial cycles.

## 5. Program phases after re-anchor

### Phase I — Method bootstrap
Purpose: establish enough methodological discipline to run bounded truth studies.

**Status:** near closure, not the permanent center of gravity.

### Phase II — Bounded theological truth studies
Run tightly scoped studies that can produce real evidence-bearing adjudications.

The current leading candidate remains a resurrection-claim study because it forces historical, testimonial, philosophical, miracle/revelation, alternative-explanation, and theological-inference machinery to interact.

It remains unauthorized until the qualification gate is passed and a study-specific preregistration is frozen.

### Phase III — Comparative doctrinal/framework research
Use qualified methods across additional claims/traditions, preserving local scope and negative results.

### Phase IV — Program-level synthesis
Only after multiple bounded adjudications:
- compare surviving claims/frameworks;
- identify distributed truths, conflicts, revisions or underdetermination;
- consider broader conclusions.

## 6. Success criteria for TFP

TFP succeeds by producing:
- better warranted conclusions about actual theological questions;
- preserved negative knowledge;
- explicit uncertainty;
- reproducible reasoning;
- defensible bounded truth claims where evidence permits them.

TFP does **not** succeed merely by:
- increasing protocol length;
- accumulating audit artifacts;
- eliminating every possible reviewer NOTE;
- repeatedly redesigning its own governance.
